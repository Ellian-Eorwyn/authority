Species, occurrence, and dataset APIs over the global biodiversity network; keyless read API, authenticated asynchronous downloads.

Guidance

Best for: Occurrence records for any taxon, filtered by geography/time · Resolving names against the GBIF taxonomic backbone · Citable Darwin Core datasets

occurrences of a species in a region occurrence-search
First species-search the name to get usageKey; then occurrence-search taxonKey=<key>&country=<ISO>.
taxonKey=3329049&country=US
bulk data beyond 100k records
Use the authenticated download API with a predicate; result is a citable DOI-stamped Darwin Core Archive.
⚠ Occurrence search caps at offset 100,000 — bulk needs the download API.
⚠ Vernacular-name search is fuzzy; prefer scientific names for precision.
