Crossref index tertiary discovery_aggregator verified

Crossref · https://www.crossref.org/ · asc-33ee865a7e80 · sources/crossref/

DOI registration agency for most scholarly publishers; its REST API serves the publisher-deposited metadata for every Crossref DOI (titles, authors, venue, dates, licences, full-text links, funders, references where open).

Guidance

Best for: Authoritative bibliographic facts for a DOI (title, authors, venue, dates, publisher) · Licence URLs and publisher text-mining links for a DOI (license[], link[]) · Resolving messy reference strings to DOIs (query.bibliographic) · Second discovery index to cross-check OpenAlex recall on the pilot topic

Routing: discovery: preferred citation: follow_primary quantitative_claims: avoid technical_claims: avoid full_text: not_applicable → resolve via publisher (Follow https://doi.org/<DOI> (or message.resource.primary.URL) to the publisher's version of record.)

keyword discovery works-query
query= words + filter=from-pub-date:2015,type:journal-article; select= to trim; cursor=* for deep paging.
--param query='electrical panel capacity heat pump' --param rows=20
reference string -> DOI works-query
query_bibliographic=<full citation string>, rows=3; accept only a hit whose title and year match.
--param query_bibliographic='Assessing electrification readiness in U.S. single-family homes electrical panel capacities 2025' --param rows=3
DOI metadata / licence work-by-doi
doi=10.x/y; read message.license[] and message.link[].
--param doi=10.1016/j.enpol.2025.114712
⚠ Relevance search is broad: many hits are loosely related; filter by type and date and read titles before fetching.
⚠ Abstracts are present only when the publisher deposited them, as JATS XML strings.
⚠ license[] describes what the publisher asserted at deposit; it is not an OA guarantee and may carry an embargo start date.
⚠ Public-pool limits are low (1 concurrent request); never parallelise against it.
⚠ Only Crossref DOIs resolve here; DataCite DOIs (datasets, some reports) 404.

Use to confirm bibliographic facts and licences before a paper enters the UPC corpus; cite the article, not Crossref.

OpenAlex index tertiary discovery_aggregator verified

OurResearch · https://openalex.org/ · asc-1957a4f7bc82 · sources/openalex/

Open catalogue of the global research system (works, authors, sources, institutions, topics) with a keyless JSON API; ingests Crossref, PubMed, repositories and Unpaywall OA locations.

Guidance

Best for: First-pass discovery of peer-reviewed and grey literature on the pilot topic (panel/service-capacity barriers to heat pump, HPWH and induction retrofits in existing US single-family homes) · Citation chasing: referenced_works (backward) and filter=cites:W… (forward) · Batch DOI -> OA status and best_oa_location before spending keyed or institutional access · De-duplicating a candidate list by DOI / OpenAlex id

Routing: discovery: preferred citation: follow_primary quantitative_claims: avoid technical_claims: avoid full_text: conditional → resolve via publisher (Resolve doi (https://doi.org/<doi>) to the publisher landing page for the version of record; use best_oa_location only as a lawful copy to read, recording its version (publishedVersion / acceptedVersion / submittedVersion) and licence.)

keyword discovery works-search
search= plain words; add filter=publication_year:2015-2026,type:article to cut noise; select= the fields you need; cursor=* to page. Fetched successfully 2026-09-27 (fch-38746ae65fef).
--param search='electrical panel capacity heat pump' --param per_page=5 --param select=id,doi,title,publication_year,best_oa_location
title-only precision search works-search
Omit search; use filter=title.search:<words> (AND of words in the title). Good for 'panel upgrade', 'service upgrade', '100 amp'. Counts as a search call (throttled anonymously; 429 when tried 2026-09-27).
--param filter='title.search:electrical panel,publication_year:2015-2026' --param per_page=10 --param select=id,doi,title,publication_year,open_access
topic-scoped discovery works-search
Find a relevant topic id from a seed paper's topics[] (T-number; e.g. the Energy Policy panel-capacity survey W4411331675 carries T10603 Smart Grid Energy Management), then filter=topics.id:Tnnnn with search= for the specific angle. Concepts (concepts.id / C-numbers) are the deprecated predecessor of topics; prefer topics.
--param filter='topics.id:T10603' --param search='electrification retrofit'
DOI lookup / batch OA check works-by-doi
doi=10.x/y (or up to 50 joined with |); read open_access.oa_status and best_oa_location.pdf_url.
--param doi=10.1016/j.enpol.2025.114712
forward citations works-search
filter=cites:W<openalex id> lists works citing a seed paper.
--param filter='cites:W4411331675' --param per_page=50
⚠ Anonymous search is throttled: on 2026-09-27 anonymous search calls (search= and filter=title.search:) got 429 three times out of four ('Anonymous search is temporarily rate-limited while the search cluster is under elevated load', Retry-After ~30 s), while DOI-filter lookups succeeded. On 429 honour Retry-After once, never loop; fall back to Crossref works-query, or get a free API key (openalex_api_key) — the real fix for deep-research.
⚠ Cost: an anonymous search cost USD 0.001 (10 credits) and a DOI filter USD 0.0001 (1 credit) against a USD 0.10 (1,000 credit) daily allowance, i.e. roughly 100 searches a day keyless. Always send select= (5 unselected records were 118 KB).
⚠ OpenAlex is a pointer layer: cite the publisher's version of record (resolve the DOI), never the OpenAlex record.
⚠ Abstracts come as abstract_inverted_index (word -> positions), not text; rebuilding one is fine for triage but it is not quotable — quote from the fetched article bytes (UPC gate).
⚠ search= is executed as fulltext.search and is noisy for technical phrases: 'electrical panel capacity heat pump' returned 57,350 hits led by PV/thermal 'panel' papers, and missed the on-topic Energy Policy panel-capacity survey (10.1016/j.enpol.2025.114712). Use title.search, quoted phrases, or seed-paper citation chasing for precision.
⚠ Without cursor=* only page 1 is returned (the CLI follows meta.next_cursor only when a cursor was sent).
⚠ ML-assigned topics and author disambiguation are imperfect; do not treat topics as a subject classification of record.
⚠ Filter values with commas or colons must stay inside one filter= parameter; separate filters with commas, alternatives with |.

Default discovery source for deep-research. Record the exact request URL and the fetch sidecar sha256 when a result set seeds a corpus, so the corpus can show how each candidate was found.

Elsevier's journal and book platform (Energy and Buildings, Energy Policy, Applied Energy, Energy Research & Social Science, The Electricity Journal …), reached programmatically through the Elsevier Article Retrieval and Object Retrieval APIs.

Guidance

Best for: Version-of-record text of Elsevier papers (Energy and Buildings, Energy Policy, Applied Energy, ERSS …) when the key or campus IP is entitled · Accepted author manuscripts (AAM-PDF) via Object Retrieval when full text is not entitled · Quoting findings, figures and numbers from Elsevier articles into a UPC corpus

Routing: discovery: not_applicable citation: preferred quantitative_claims: preferred technical_claims: preferred full_text: conditional → resolve via none_required (Publisher of record for its own journals.)

article metadata/abstract article-by-doi
doi=10.1016/…, view=META_ABS, http_accept=text/xml.
--param doi=10.1016/j.enpol.2025.114712 --param view=META_ABS
full text of record (entitled) article-by-doi
view=FULL from a UC Davis campus/VPN egress, or with an insttoken (not injectable by the CLI yet). Check originalText is present; absence = not entitled.
--param doi=10.1016/j.enpol.2025.114712 --param view=FULL
accepted manuscript objects-by-doi
List objects; if a choice whose @type contains AAM exists, fetch its $ URL with the same key header (outside the CLI: the object URL is not a declared endpoint); record version=acceptedVersion in UPC.
--param doi=10.1016/j.enpol.2025.114712
⚠ 'AUTHENTICATION_ERROR — Requestor configuration settings insufficient' means the key is not provisioned for that API (or not entitled), not that the key is wrong.
⚠ A 200 response without originalText is metadata only: the key/IP is not entitled to full text for that item.
⚠ AAMs are post-peer-review but not the typeset version: never cite page numbers from them as the journal's.
⚠ Never scrape www.sciencedirect.com PDF routes (Cloudflare-gated against automation even with entitlement); use these APIs or a human click (pdf-harvest assisted mode).
⚠ Bulk full-text pulls need a TDM entitlement: ask the UC Davis library for an insttoken rather than looping on campus IP.

Use only for DOIs with prefix 10.1016 (and other Elsevier prefixes). Try Unpaywall first; come here for the version of record or when no OA copy exists.

Database of legal open-access copies of scholarly articles, keyed by DOI: for each DOI, the OA status and every known free-to-read location with version and licence.

Guidance

Routing: discovery: not_applicable citation: follow_primary quantitative_claims: avoid technical_claims: avoid full_text: preferred → resolve via publisher (Cite the published article (DOI); the OA location is only where the bytes were read. ⚠ license may be null even for a free copy; free-to-read is not free-to-redistribute.
